# Indicaciones y descripción del proyecto

Este repositorio contiene dos ejemplos principales:

- Un juego interactivo de piedra, papel o tijera (`game/`).
- Un generador de gráficas basado en datos CSV (`projectCharts/`).

## Cómo ejecutar el juego

```bash
cd game
python3 main.py
```

## Cómo ejecutar el generador de gráficas

```bash
cd projectCharts
python3 main.py
```

> Asegúrate de instalar las dependencias listadas en `projectCharts/requeriments.txt` (por ejemplo, `matplotlib`) y de crear la carpeta `projectCharts/img/` antes de ejecutar el script.
